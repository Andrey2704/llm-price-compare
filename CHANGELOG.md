# Changelog

Все заметные изменения проекта. Формат — по мотивам Keep a Changelog, версии — SemVer.

## [1.1.0] — 2026-10-29

### Добавлено

- `list --format json|csv` и `compare --format json|csv` — машинно-читаемый вывод для скриптов
- `list --sort blended|context|name` — сортировка по стоимости под объём, по размеру контекста и по имени
- `list --free`, `--provider`, `--query` — фильтры по free-тиру, провайдеру и подстроке
- `validate` — проверка целостности `prices.json` (обязательные поля, отрицательные цены, дубли id) и свежести снимка через `--max-age-days`
- общий флаг `--data PATH` — подмена файла цен
- `pyproject.toml` с console-script `llm-price-compare`
- CI на GitHub Actions: Python 3.9 / 3.11 / 3.13 + `validate`

### Изменено

- CLI разбит на чистые функции (`filter_models`, `sort_models`, `to_records`) — их проще тестировать
- вывод `list` получил колонку «Итого» и маркер `free-tier`
- `compare` показывает стоимость под объём, а не только цены за 1M
- ошибки чтения данных печатаются по-человечески и возвращают код 2

### Тесты

- 4 теста → 23: форматирование, фильтры, сортировки, экспорт, валидация, ошибки загрузки
